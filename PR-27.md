## Ranked shortlist

Opulent 15, Power 14, Death 13, Oath 12, Rebirth 11, Life 10. Everything else stays at 1.0 (0.5 for the blue tier).

The numbers matter less than the two properties they encode: a strict order among the six, and a gap wide enough that no pile of ordinary runes out-scores one of them. `ShippedCatalogFileHasAll34RunesWithWeights` asserts both.

## One badge, not several

The badge used to go to every rune tied at the top weight, which handed the comparison straight back to the user.

The game's choice is a **row** — you take a row whole — so the recommendation is now a row first and a rune second: the highest-scoring row, then the rune inside it that earned the score. Ties break (best single rune, then topmost row) rather than being shared, because two rows worth the same are interchangeable and comparing them is exactly the work the badge exists to remove.

The RUNE-4 guard stands: with nothing bound, every sprite weighs the same and no badge is awarded at all.

On `1 Raw.png` this is visible — rows 2 and 4 both hold Opulent and score identically, and the fixture test now asserts exactly one badge on the topmost of them.

## Shipped sprite seed

Naming a sprite is the one step the detector cannot do — it takes a human to say which shape is Opulent. 46 named sprites covering 33 of the 34 runes (all but Bait, which has no icon) now ship embedded as `ocr/rune-seed.json` and merge into a fresh library on first run.

Three things keep it from fighting the user:

- it only adds shape hashes the library has never seen, so nothing already bound is overwritten;
- it runs once per seed version — the applied version is persisted — so a sprite forgotten on purpose does not reappear next launch;
- it refuses a seed from a different identity hash generation, whose hashes name crops the detector no longer produces.

`scripts/export-rune-seed.ps1` regenerates it from any `config/rune-catalog.json`. `TheShippedSeedIsCurrentAndCoversTheRuneList` fails loudly if `CurrentHashVersion` is bumped without a re-export, which would otherwise silently put every new install back to naming 33 sprites by hand.

`build-local.ps1 -FreshLibrary` now means "reset to the shipped seed" rather than "start empty"; its help text says so.

## Library picker

The six read as `Top (15)` rather than `Custom (15)`. They stay `Custom` as a *level*, so picking a named level over one of them is an explicit change and never a silent rounding.
