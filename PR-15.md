Two reports from the user, both right.

## 1. The latch was still re-reading and re-mangling the first row

Two causes, both mine:

- **It keyed the session on the row text.** OCR text jitters between reads, so a wobble started a "new panel" and re-read everything.
- **It replaced the latched read whenever a later one found *more* runes.** A mangled read that splits a row into extra cells has more — so the bad read won. That rule was my addition to handle a first read taken mid-hover, and it cost more than it bought.

> "we should parse the values ONLY ONCE on load and we can dismiss everything when the screen closes. idk why we would need to re-read and reparse, the runes NEVER change during the same window session"

A session now runs from the panel being detected to it not being — exactly that. A better read may still replace the latched one during the first **1.5s**, so a read taken mid-animation is not frozen in; after that the panel is fixed until it closes. "Nothing latched yet" stays distinct from "frozen", so a panel that opens before its icons draw still latches when they arrive.

## 2. The magazine column now matches what was drawn

Icons only, in a narrow strip against the left edge. Reset button at the top. Hover an icon to see its name, right-click to dismiss it, scroll when it overflows.

**This one cannot be click-through** — it has to receive hover and right-click. `WS_EX_TRANSPARENT` is gone; `WS_EX_NOACTIVATE` stays, so it never takes focus from the game. The gutter where the hover label is drawn is chroma-keyed, so everywhere outside the painted strip still passes clicks through to the game.

## Not verified

The overlay's behaviour on screen — that it lands on the left edge, that right-click reaches it rather than the game, that the strip does not swallow clicks the user wanted in game. The geometry (row hit-testing, scroll limits, the reset button never being mistaken for a row, rows scrolled out of view not being clickable) is tested directly, and the latch's rules are pinned by an executable restatement of them.
